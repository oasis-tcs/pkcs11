## Common attributes

Objects are identified by two main attributes that should be present on every
object, **CKA_CLASS** and **CKA_UNIQUE_ID**. Each Object class further defines
which attibutes are mandatory or optional for objects of that class, se further
sections for additional details.

### The CKA_CLASS attribute

The **CKA_CLASS** attribute is a value of type **CK_OBJECT_CLASS** that
identifies the object class (type) of the object.


### The CKA_UNIQUE_ID attribute

Any time a new object is created, a value for **CKA_UNIQUE_ID MUST** be
generated by the token and stored with the object. The specific algorithm used
to generate unique ID values for objects is token-specific, but values generated
MUST be unique across all objects visible to any particular session, and SHOULD
be unique across all objects created by the token. Reinitializing the token,
such as by calling **C_InitToken**, MAY cause reuse of **CKA_UNIQUE_ID** values.

Any attempt to modify the **CKA_UNIQUE_ID** attribute of an existing object or
to specify the value of the **CKA_UNIQUE_ID** attribute in the template for an
operation that creates one or more objects MUST fail. Operations failing for
this reason return the error code **CKR_ATTRIBUTE_READ_ONLY**.


### The CKA_TIMESTAMP attribute

Any time a new object is created, and the token reports the **CKF_CLOCK_ON_TOKEN**
flag, the **CKA_TIMESTAMP MUST** be generated by the token and stored with the
object.

The **CKA_TIMESTAMP** is a fixed length 24 byte attribute that contains an
RFC 3339 timestamp.  The attribute represents the time as a fixed length  value
with millisecond precision in Zulu time.  If a token is unable to provide the
complete time with millisecond precision, it **MUST*** populate the missing values
with '0'.  For example: "2026-10-07T18:30:23.000Z".

~~~{.c}
#define CK_TIMESTAMP_LENGTH 24
~~~

Any attempt to modify the **CKA_TIMESTAMP** attribute of an existing object or
to specify the value of the **CKA_TIMESTAMP** attribute in the template for an
operation that creates one or more objects MUST fail. Operations failing for
this reason return the error code **CKR_ATTRIBUTE_READ_ONLY**.

Modifying an object will not result in any modification of the **CKA_TIMESTAMP**
attribute.  The **CKA_TIMESTAMP** attribute is only intended to report the time the
object was created.

If an existing object is being copied, a new **CKA_TIMESTAMP MUST** be assigned
to the new copy of the object by the token.

If an existing object is being recreated via **CreateObject**, **C_DeriveKey**,
**C_UnwraKey**, **C_UnwrapKeyAuthenticated**, **C_DecapsulateKey** or any other
operation that can recreate a object, a token **MUST** consider this to be a new
object and assign it a fresh **CKA_TIMESTAMP** attribute.
