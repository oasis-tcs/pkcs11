## Storage Objects

This is not an object class; hence no **CKO_** definition is required. It is
a category of object classes with common attributes for the object classes
that follow.

| Attribute        | Data Type      | Meaning                             |
|------------------|----------------|-------------------------------------|
| CKA_TOKEN        | CK_BBOOL       | CK_TRUE if object is a token object; CK_FALSE if object is a session object.  Default is CK_FALSE. |
| CKA_PRIVATE      | CK_BBOOL       | CK_TRUE if object is a private object; CK_FALSE if object is a public object.  Default value is token-specific, and may depend on the values of other attributes of the object. |
| CKA_MODIFIABLE   | CK_BBOOL       | CK_TRUE if object can be modified Default is CK_TRUE. |
| CKA_LABEL        | RFC2279 string | Description of the object (default empty). |
| CKA_COPYABLE     | CK_BBOOL       | CK_TRUE if object can be copied using C_CopyObject. Defaults to CK_TRUE.  Can’t be set to TRUE once it is set to FALSE. |
| CKA_DESTROYABLE  | CK_BBOOL       | CK_TRUE if the object can be destroyed using C_DestroyObject. Default is CK_TRUE. |
| CKA_CREATION_TIMESTAMP ^2,4,6^ | RFC2279 string | The time the object was created. |
table: Common Storage Object Attributes

- Refer to Table 13 for footnotes

Only the **CKA_LABEL** attribute can be modified after the object is created.
(The **CKA_TOKEN**, **CKA_PRIVATE**, and **CKA_MODIFIABLE** attributes can
be changed in the process of copying an object, however.)

The **CKA_TOKEN** attribute identifies whether the object is a token object
or a session object.

When the **CKA_PRIVATE** attribute is CK_TRUE, a user may not access the
object until the user has been authenticated to the token.

The value of the **CKA_MODIFIABLE** attribute determines whether or not an
object is read-only.

The **CKA_LABEL** attribute is intended to assist users in browsing.

The value of the **CKA_COPYABLE** attribute determines whether or not an
object can be copied. This attribute can be used in conjunction with
**CKA_MODIFIABLE** to prevent changes to the permitted usages of keys and
other objects.

The value of the **CKA_DESTROYABLE** attribute determines whether the object
can be destroyed using **C_DestroyObject**.

### The CKA_CREATION_TIMESTAMP attribute

Any time a new storage object is created, and the token reports the
**CKF_CLOCK_ON_TOKEN** flag, the **CKA_CREATION_TIMESTAMP MUST** will be
generated by the token and stored with the object.

If the token does not report the **CKF_CLOCK_ON_TOKEN** flag, the
**CKA_CREATION_TIMESTAMP** attribute is not present on any object. A call to
**C_GetAttributeValue** that requests it returns
**CKR_ATTRIBUTE_TYPE_INVALID**, and a search template that specifies it matches
no objects.

The **CKA_CREATION_TIMESTAMP** is a fixed length 24 byte attribute that contains
an RFC 3339 timestamp.  The attribute represents the time as a fixed length
value with millisecond precision in Zulu time.  If a token is unable to provide
the complete time with millisecond precision, it **MUST** populate the missing
values with '0'.  For example: "2026-10-07T18:30:23.000Z".

~~~{.c}
#define CK_CREATION_TIMESTAMP_LENGTH 24
~~~

Any attempt to modify the **CKA_CREATION_TIMESTAMP** attribute of an existing
object **MUST** fail and return the error code **CKR_ATTRIBUTE_READ_ONLY**.

Any attempt to specify the value of the **CKA_CREATION_TIMESTAMP** attribute
in the template for an operation that creates one or more objects **MUST**
fail and return the error code **CKR_ATTRIBUTE_TYPE_INVALID**.

Modifying an object will not result in any modification of the
**CKA_CREATION_TIMESTAMP** attribute.  The **CKA_CREATION_TIMESTAMP** attribute
is only intended to report the time the object was created.

If an existing object is being copied, a new **CKA_CREATION_TIMESTAMP MUST** be
assigned to the new copy of the object by the token.

If an existing object is being recreated via **C_CreateObject**,
**C_DeriveKey**, **C_UnwrapKey**, **C_UnwrapKeyAuthenticated**,
**C_DecapsulateKey** or any other operation that can recreate an object, a token
**MUST** consider this to be a new object and assign it a fresh
**CKA_CREATION_TIMESTAMP** attribute.
